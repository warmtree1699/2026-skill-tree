# 🌳 2026 技能樹

一個純靜態的互動式技能樹網站，整理前端、後端與 PM 的學習路線，並可逐項標記學習進度。不需要任何建置工具或套件，直接用瀏覽器開啟即可。

## 頁面

| 頁面 | 內容 |
| --- | --- |
| [index.html](index.html) | 前端 / 後端工程師 & PM 技能樹：JavaScript、CSS、Backend、PM 四條路線 |
| [vue-nuxt.html](vue-nuxt.html) | Vue + Nuxt 技能樹：Vue 3、Nuxt 3 兩條路線 |

每條路線依「基礎能力 → 框架 / 生態系 → 工程化 / 進階」等層級，由淺入深排列。

## 功能

- **分類篩選**：上方分頁可切換「全部顯示」或只看單一路線。
- **進度追蹤**：點擊技能節點可在三種狀態間循環切換：
  - 未開始
  - 📖 學習中
  - ✅ 已掌握

  每條路線上方會顯示進度條與統計（學習中算半分）。
- **自動儲存**：進度存在瀏覽器的 `localStorage`，每個頁面各自獨立保存，重新整理後仍會保留。
- **深色模式**：右上角 🌙 / ☀️ 按鈕切換主題，偏好設定同樣會被記住。
- **響應式版面**：依螢幕寬度自動調整為 4 / 2 / 1 欄。

## 使用方式

直接用瀏覽器開啟 `index.html` 即可。

若想透過本機伺服器瀏覽，可以使用任一靜態伺服器，例如：

```bash
npx serve .
# 或
python -m http.server 8000
```

> 注意：進度記錄存在瀏覽器本機，更換瀏覽器、使用無痕模式或清除網站資料後會重置。

## 專案結構

```
.
├── index.html      # 前端 / 後端 / PM 技能樹
├── vue-nuxt.html   # Vue + Nuxt 技能樹
├── style.css       # 共用樣式（含淺色 / 深色主題變數）
└── script.js       # 分頁篩選、進度追蹤、主題切換
```

## 新增或修改技能

技能內容直接寫在 HTML 中，`script.js` 會自動套用進度追蹤：

- 每條路線是一個 `<section class="column" data-cat="...">`，`data-cat` 需與上方分頁按鈕的 `data-cat` 對應。
- 單一技能使用 `.node`；若一個節點底下有多個可個別勾選的小項目，使用 `.node.group` 搭配 `.skill-item`。
- 顏色定義在 `style.css` 的 `:root`（例如 `--js`、`--vue`），新增路線時記得一併加上對應的顏色變數。

> 進度是依節點在路線中的**順序**儲存的，若在中間插入或刪除節點，既有的進度標記可能會錯位。
